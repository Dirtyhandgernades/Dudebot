## P0-1: official Nasdaq halt/optional Massive source transport provenance

Identified an independent-source intake weakness in `backtest/obsidian_independent_quote_halt.py`: its GET-only Nasdaq Trader RSS and optional Massive quote requests used the requests library's implicit redirect-following behavior and did not verify the actual response URL. A redirected or substituted HTTP 200 could have been parsed and described as Nasdaq-official halt evidence or as a Massive independent quote without authenticating the expected endpoint. A redirect could also unnecessarily expose request details to an unexpected host.

Research-only correction: both requests now explicitly use `allow_redirects=False`. An HTTP 200 is accepted only when the observed response URL matches the pinned HTTPS host and path. Nasdaq RSS additionally requires the exact `feed=tradehalts` query; Massive quote URL query credentials are never logged or archived. Redirects and origin mismatches fail closed with `HALT_RSS_HTTP_<status>`, `INDEPENDENT_QUOTES_HTTP_<status>`, `HALT_RSS_UNTRUSTED_RESPONSE_ORIGIN`, or `INDEPENDENT_QUOTES_UNTRUSTED_RESPONSE_ORIGIN`. In those cases halt evidence remains unavailable, optional quotes remain disconnected, and `trade_authorized=false`. A pinned RSS response remains only a finite, as-of halt feed, **not** a guarantee that a symbol is open or SMG-shortable. A matching Massive endpoint is **not** evidence of an authenticated real-time subscription, official closing auction, or independent underlying exchange feed.
