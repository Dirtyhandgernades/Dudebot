## Material software integrity finding and CI repair

The finite Nasdaq Trader RSS parser previously deduplicated on (symbol, halt timestamp, explicit resume timestamp), allowing two source rows to claim **different reason codes** for the same halt event, or incompatible explicit trade-resumption timestamps, without an ambiguity warning. Such rows could be treated as separate observations. This checkpoint introduced an event-level conflict guard while retaining exact duplicate-row deduplication.

Initial implementation [`402f8a15f405e692425c92af2372c841da46da55`](https://github.com/Dirtyhandgernades/Dudebot/commit/402f8a15f405e692425c92af2372c841da46da55) correctly rejected contradictory explicit resumption and reason claims but also rejected an existing conservative scenario where one row has an **incomplete** resumption and another has an explicit resumption. Both initial hosted CI jobs failed on that existing test ([independent-source #41411641319](https://github.com/Dirtyhandgernades/Dudebot/actions/runs/41411641319), [prospective #41411641372](https://github.com/Dirtyhandgernades/Dudebot/actions/runs/41411641372)). This failure was inspected in the runner logs, not hidden.

Repair [`d1513572204cd916c21b8584d1316c4b30bcd7d6`](https://github.com/Dirtyhandgernades/Dudebot/commit/d1513572204cd916c21b8584d1316c4b30bcd7d6) retains both incomplete and explicit-resumption rows (so unresolved status still takes precedence), but rejects two incompatible **explicit** resumption times or conflicting reason codes for the same (symbol, halt timestamp). It deduplicates only exactly repeated source claims. Contradictory feed claims now cause the collector to censor the halt source as `HALT_RSS_MALFORMED_OR_UNVERIFIABLE`, not assert exchange clearance or SMG short approval. Three new regression tests cover exact duplicates, conflicting reason codes, and conflicting explicit resumptions.
